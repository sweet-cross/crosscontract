# About

This package provides tools to manage data contracts based on the [Frictionless data standard](https://frictionlessdata.io/). Additionally, it allows you to interact with the [CROSS Data Platform](https://sweet-cross.ch/data-contracts).

The [CROSS project](https://sweet-cross.ch) is part of the [SWEET-CoSi](https://www.sweet-cosi.ch/) funded by the [Swiss Federal Office of Energy](https://www.bfe.admin.ch/bfe/de/home/forschung-und-cleantech/foerderprogramm-sweet.html).
